# 🎯 ZenTask - Premium To-Do List App

A beautifully designed, responsive to-do list application with an elegant glassmorphism UI, dark mode support, and advanced task management features.

## ✨ Features

### Core Functionality
- ✅ **Add & Manage Tasks** - Create, edit, and delete tasks with ease
- 🏷️ **Smart Categorization** - Organize tasks by category (Personal, Work, Study, Other)
- 📊 **Priority Levels** - Set task priority (Low, Medium, High)
- 📅 **Due Dates** - Assign due dates to tasks for better planning
- 🔍 **Search & Filter** - Quickly find tasks by keywords or status
- ✨ **Status Tracking** - Mark tasks as complete/pending

### UI/UX Enhancements
- 🌓 **Dark Mode** - Toggle between light and dark themes with one click
- 🎨 **Glassmorphism Design** - Modern, premium visual aesthetic
- 📱 **Fully Responsive** - Perfect experience on desktop, tablet, and mobile
- ⚡ **Smooth Animations** - Delightful transitions and interactions
- 🎭 **Animated Background Blobs** - Dynamic, engaging visual effects

### Advanced Features
- 💾 **Local Storage** - All tasks persist in browser (no database needed)
- 🔐 **Privacy First** - All data stored locally on your device
- 📋 **Task Editing** - Edit task details in a modal dialog
- 🗑️ **Bulk Operations** - Clear all completed tasks at once
- 📊 **Task Statistics** - See pending task count at a glance

## 🎯 How to Use

### Getting Started
1. Open the application in your web browser
2. Click **"Get Started"** to enter the app
3. Start adding tasks!

### Adding a Task
1. Enter task description in the input field
2. Select a category from the dropdown
3. Choose priority level
4. Pick a due date (optional)
5. Click **"Add Task"** or press **Enter**

### Managing Tasks
- **Complete:** Click the checkbox to mark task as done
- **Edit:** Click the edit icon to modify task details
- **Delete:** Click the trash icon to remove the task
- **Search:** Use the search bar to filter tasks by keyword
- **Filter:** Click All, Pending, or Completed to view specific tasks
- **Clear:** Remove all completed tasks with one click

### Theme Toggle
- Click the moon/sun icon in the header to switch between light and dark modes
- Your preference is saved automatically

## 🛠️ Installation

### Option 1: Direct Browser Access
Simply open `index.html` in your web browser. No server required!

### Option 2: Local Server (Recommended)
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (with http-server)
npx http-server

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000` in your browser.

## 💾 Data Storage

- All tasks are stored in the browser's **LocalStorage**
- Data persists even after closing the browser
- No data is sent to any server
- To clear data: Open DevTools → Application → Local Storage → Clear
